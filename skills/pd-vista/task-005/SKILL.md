# PD-VISTA router for organizing mixed document files

First inventory the supplied files and task instructions. Build a clear classification
plan, then place every input into exactly one requested subject folder without changing
file names or file contents.

The original planning and document-format modules are initially hidden. After public
feedback about missing files, classification, planning, or a particular document
format, the controller may disclose exactly one module under
`modules/<module-id>/SKILL.md`. Read a disclosed module before the next attempt and
use only its visible guidance.

Do not assume undisclosed modules exist, do not inspect hidden verifier state, and do
not leave files outside the required subject folders.
